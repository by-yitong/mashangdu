## 变量：程序里的储物盒

程序的本质是处理数据，变量就是存放数据的储物盒，每个盒子有名字和类型。Go 是静态类型语言：盒子在创建时就要说清楚能装什么类型的东西，装进去以后不能换类型。最常用的声明方式是短变量声明，用 := 符号一步完成声明加赋值：

```go
package main

import "fmt"

func main() {
	age := 25
	name := "小明"
	height := 1.72
	isStudent := true
	fmt.Println(name, age, height, isStudent)
}
```

这段代码创建了四个变量，正好对应 Go 最常用的四种基本类型：

- `int`：整数，比如年龄、数量；
- `string`：字符串，也就是一段文字，要用双引号包起来；
- `float64`：小数，比如身高、价格；
- `bool`：布尔值，只有 true 和 false 两种取值，表示真或假。

Go 还有一条新手必知的铁律：声明了的变量必须使用，否则编译直接报错，提示 declared and not used。这不是刁难，而是帮你及早发现没写完的逻辑。建议你做个小实验：把上面代码里的 height 那一行删掉，但保留打印它的语句，运行看看报错信息长什么样。编程语言的性格，就是在这样的小碰撞中慢慢熟悉的。

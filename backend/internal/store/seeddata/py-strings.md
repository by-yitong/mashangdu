## 第3章 · 字符串与格式化

字符串是程序里最常见的数据：用户名、提示语、文件路径全是字符串。Python 处理字符串的能力非常强，本章我们学最核心的三件事：把变量嵌进字符串（格式化）、拆分与拼接、按下标截取。

先说格式化。把数字、变量拼进一句话里，用加号连接又麻烦又容易出错，Python 3.6 之后推荐用 f-string：在引号前加一个 f，花括号里直接写变量甚至表达式，代码读起来几乎就是最终输出的样子：

```python
name = "小明"
age = 12
pi = 3.14159

# f-string：花括号里可以放变量，也可以放表达式
print(f"{name} 今年 {age} 岁，明年 {age + 1} 岁")

# 冒号后接格式说明：.2f 表示保留两位小数
print(f"圆周率约等于 {pi:.2f}")   # 圆周率约等于 3.14

# 字符串可以用 + 拼接，用 * 重复
print("ab" + "cd")   # abcd
print("啦" * 3)      # 啦啦啦
```

字符串还有一整套现成的方法，覆盖了日常处理的绝大多数需求。方法跟在字符串变量后面用点号调用，返回新字符串，原字符串不会被修改：

```python
s = "  Hello, Python  "

print(s.strip())                   # 去掉两端空格 -> Hello, Python
print(s.strip().upper())           # 转大写 -> HELLO, PYTHON
print(s.replace("Python", "世界")) # 替换子串 -> "  Hello, 世界  "

# split 按分隔符拆成列表，join 把列表拼回字符串，两者互为逆操作
csv = "苹果,香蕉,橘子"
parts = csv.split(",")
print(parts)          # ['苹果', '香蕉', '橘子']
print("、".join(parts))  # 苹果、香蕉、橘子

# 下标从 0 开始，负数从末尾往前数；切片含头不含尾
word = "Python"
print(word[0])    # P
print(word[-1])   # n
print(word[0:3])  # Pyt
print(len(word))  # len 函数取长度
```

日常最常用的字符串方法列在这里，记熟它们能解决大部分文本处理问题：

- `strip()`：去掉两端的空白字符；
- `upper()` / `lower()`：转大写、转小写，比较用户输入前先统一大小写是好习惯；
- `replace(old, new)`：替换子串；
- `split(sep)` / `join(list)`：拆分与拼接；
- `startswith(x)` / `endswith(x)`：判断开头结尾，返回 True 或 False；
- `find(x)`：查找子串位置，找不到返回 -1。

有一个新手常见问题顺带一提：字符串是不可变的，`word[0] = "J"` 这样的写法会直接报错。想"修改"字符串，只能像上面的例子那样，用方法生成一个新字符串再赋值回去。

f-string 还支持更细的排版控制：冒号后写大于号加数字表示右对齐并占指定宽度，如 {name:>10}，居中用 ^，打印表格时配合循环能让输出整整齐齐。多行文本用三引号字符串，里面的换行原样保留，写长提示语很方便。另外两个小知识：转义字符以反斜杠开头，最常见的 \n 表示换行、\t 表示制表符；想让反斜杠不做转义，在字符串前加 r，比如 r"C:\new" 会原样保留路径里的反斜杠，处理 Windows 路径时特别有用。练习时多打印中间结果，字符串处理的每一步都看得见，错了立刻能定位。比如处理用户输入的经典三连：先 strip 去空格、再 lower 统一大小写、最后比较，一行连起来写就是标准起手式。

小结：f-string 负责把数据嵌进文本，strip、split、join、replace 负责清洗和组装，下标与切片负责精确截取。建议写一个小练习：给定 "2026-10-15" 这样的日期字符串，用 split 拆出年、月、日，再用 f-string 拼成 "2026 年 10 月 15 日"。

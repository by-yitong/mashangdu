## 把 Python 装进你的电脑

工欲善其事，必先利其器，学 Python 的第一步是安装它。打开官网 python.org 的下载页面，根据操作系统下载最新版安装包。Windows 用户特别注意：安装第一步的界面里务必勾选 Add Python to PATH 这个选项，否则终端会找不到 python 命令；macOS 用户按提示一路继续即可。

安装完成后打开终端，输入：

```text
python --version
```

看到类似 Python 3.12.x 的输出就说明安装成功了。接着只输入 python 并回车，你会进入一个以 >>> 开头的界面，这就是 REPL（交互式解释器）。它像一台会说话的计算器：你输入一行代码，它立刻回你一个结果。来试试：

```python
>>> 1 + 2
3
>>> print("你好，Python")
你好，Python
```

对初学者来说，REPL 是最好的朋友，因为反馈是即时的，写错了马上就能知道。建议你用它完成三件小事：

- 把它当计算器，试试加减乘除和括号；
- 输入一段用引号包起来的文字，观察它的回显规则；
- 故意输入 1 + "a" 看看报错信息长什么样。

想退出 REPL，Windows 上按 Ctrl+Z 再回车，macOS 上按 Ctrl+D。环境就绪，下一章我们正式开始写代码。

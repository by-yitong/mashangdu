## 第6章 · 面向对象入门

前面我们把函数和数据分开管理，面向对象编程（OOP）换了个思路：把数据和操作这些数据的函数绑定成一个整体，叫作类（class）。类好比一张图纸，按照图纸造出来的具体对象叫实例（instance）。比如"学生"是图纸，小明、小红是按图纸造出的两个实例。

定义类用 class 关键字。类里最特殊的方法是 `__init__`（前后各两条下划线），创建实例时自动执行，负责给对象设置初始数据。第一个参数 self 代表"对象自己"，Python 会自动传入：

```python
class Student:
    def __init__(self, name, age):
        # __init__ 是构造方法，创建对象时自动执行
        # 挂在 self 上的变量叫实例属性，每个对象各有一份
        self.name = name
        self.age = age

    def introduce(self):
        # 类里的方法第一个参数永远是 self，调用时不用传
        print(f"我叫{self.name}，今年{self.age}岁")

# 创建实例：类名加括号，传入 __init__ 需要的参数
s1 = Student("小明", 12)
s2 = Student("小红", 13)
s1.introduce()  # 我叫小明，今年12岁
s2.introduce()  # 我叫小红，今年13岁

print(s1.name)  # 属性也能直接用点号访问
```

第二个核心概念是继承：新的类可以站在已有类的肩膀上，自动拥有它的属性和方法，再按需覆盖或扩展。继承表达的是"是一种"的关系——狗是一种动物，猫也是一种动物：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name}在叫")


class Dog(Animal):  # 括号里写父类，表示继承
    def speak(self):  # 重写（覆盖）父类的方法
        print(f"{self.name}：汪汪！")


class Cat(Animal):
    def speak(self):
        print(f"{self.name}：喵~")


for a in [Dog("旺财"), Cat("咪咪")]:
    a.speak()   # 同样的调用，不同的表现：这叫多态
```

上面循环里对每个对象都调用 `a.speak()`，但狗和猫各自给出了不同回答——同一接口、不同实现，这就是"多态"。它让你写的循环代码不关心对象具体是什么，只要"会叫"就行。

初学面向对象，记住这几条实践原则比记语法更重要：

- 类名用大驼峰（StudentBook），方法名和函数一样用小写下划线；
- 不是所有代码都需要类：只是几个函数能解决的事，别硬套 class；
- 实例属性在 `__init__` 里初始化，让对象一出生状态就完整；
- 子类重写方法后想用父类版本，用 `super().方法名()` 调用；
- Python 没有真正的私有属性，约定属性名前加下划线（如 `_count`）表示"内部使用，外部别碰"。

什么时候该用类？一个简单的判断：当一组数据和这组数据的操作总是成对出现（比如学生和选课、账户和存取款），把它们包成一个类会让代码更好维护；如果整个程序只有一条数据，用字典就够了。

补充两个实用细节：直接写在类体里、不在 __init__ 里的变量叫类属性，所有实例共享同一份，适合放常量或计数器；给类定义 __str__ 方法可以定制 print 的输出样子，比如返回 f"{self.name}（{self.age} 岁）"，之后打印对象就会显示这句友好文案，而不是默认的 <__main__.Student object> 这样的难懂信息。

小结：类把数据（属性）和行为（方法）打包，`__init__` 负责初始化，self 代表对象自己，继承加多态让代码可以扩展而少改动。练习建议：写一个 BankAccount 类，有余额属性和 deposit、withdraw 两个方法，取款超过余额时打印提示。

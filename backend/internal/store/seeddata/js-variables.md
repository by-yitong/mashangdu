## 第2章 · 变量与类型

程序要处理数据，变量就是给数据起名字。JS 声明变量有两个关键字：let 声明可以重新赋值的变量，const 声明常量，一旦赋值就不能再改。现代 JS 的最佳实践是：默认用 const，确实需要重新赋值时才用 let，var 是历史遗留，新代码不写：

```javascript
let score = 95;       // let 声明可以重新赋值的变量
score = 98;           // 合法

const pi = 3.14;      // const 声明常量，不能重新赋值
// pi = 3.15;         // 报错：Assignment to constant variable

let city = "北京";
let ok = true;
let nothing = undefined;

console.log(typeof score);   // "number"
console.log(typeof city);    // "string"
console.log(typeof ok);      // "boolean"
```

JS 是动态类型语言：变量本身没有固定类型，类型属于值。常用类型有这么几种：

- number：整数和小数都是它，如 42、3.14（JS 没有单独的整数类型）；
- string：字符串，单引号、双引号、反引号都可以；
- boolean：true 和 false；
- undefined：声明了但没赋值时的默认值；
- null：表示"故意留空"；
- 还有 object（对象）和后面会学的 function。

字符串有一件利器：模板字符串。用反引号（键盘左上角、数字 1 左边那个键）包住字符串，${} 里可以嵌变量甚至表达式，比加号拼接清爽得多：

```javascript
let name = "小明";
let age = 12;

// 模板字符串：反引号包住，${} 里写变量或表达式
console.log(`${name} 今年 ${age} 岁，明年 ${age + 1} 岁`);

// 新手经典大坑：加号遇到字符串会变成"拼接"
console.log("5" + 3);   // "53"，数字被拉去拼字符串了
console.log("5" - 3);   // 2，减号没有拼接含义，字符串被转成数字

// 拿不准时显式转换，代码意图更清楚
console.log(Number("5") + 3);   // 8
console.log(String(123));       // "123"
console.log(parseInt("42px"));  // 42，从开头解析数字
```

`"5" + 3` 得到 "53" 这件事值得单独强调：这是 JS 被吐槽最多的设计，也是无数 bug 的源头。记住规则——加号两侧只要有一个字符串，就做拼接；需要数学运算时，先用 Number() 转换。

还有一个关于比较的坑顺便讲掉：`==` 会先把两边转成同类型再比较，所以 `"5" == 5` 是 true；`===` 严格比较类型和值，`"5" === 5` 是 false。实际写代码请始终用 `===` 和 `!==`，让类型转换显式发生，代码才可预测。

另外，const 锁住的是"赋值动作"，不是内容本身：用 const 存的对象和数组，内部的属性和元素照样可以增删改，只是不能把整个变量换成另一个值。

变量命名遵循小驼峰风格：第一个单词小写，后面的单词首字母大写，如 userName、maxScore。名字要有含义，存天数的变量叫 d，三天后你自己都不认识；叫 daysLeft 就一目了然。undefined 和 null 的分工也值得记：undefined 是"系统没给值"的默认状态，null 是"程序员主动表示空"，判断变量是否可用时两者都要考虑到。练习时不妨故意声明一个不赋值的变量，用 typeof 看看它是什么。再把 == 和 === 各试一遍，观察输出差异。另外提醒一句：变量不声明直接赋值也能跑，但那会造成全局变量泄漏，严格模式下会报错，请始终带上 let 或 const，让工具替你把关。

小结：const 优先、let 次之、var 不用；类型挂在值上，typeof 能查看；模板字符串负责拼接，Number 和 String 负责显式转换，比较一律 ===。练习建议：在控制台声明你的姓名、年龄和爱好，用一条模板字符串打印自我介绍。

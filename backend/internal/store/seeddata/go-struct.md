## 第7章 · 结构体与方法

前面的章节里，数据都是散着放的：一个变量存名字，一个变量存年龄。真实项目里，"一个用户""一张订单"往往由多个字段组成，这时就需要结构体（struct）：它把一组相关的数据打包成新类型，让程序里出现你自己定义的概念。Go 用 type 加 struct 定义结构体：

```go
package main

import "fmt"

// 定义结构体：把相关的数据打包成一种新类型
type User struct {
	Name string
	Age  int
}

func main() {
	// 创建方式一：按字段名初始化（推荐，字段顺序随意）
	u := User{Name: "小明", Age: 12}
	fmt.Println(u.Name, u.Age) // 小明 12

	u.Age++ // 用点号读写字段
	fmt.Println(u) // {小明 13}

	// 创建方式二：不按字段名，按顺序给值（少用，改字段顺序就出错）
	v := User{"小红", 11}
	fmt.Println(v)
}
```

结构体只有数据还不够，我们还想让它"会做事"。Go 给结构体挂函数的方式叫方法：在 func 和函数名之间加一个接收者（receiver），看起来就像这个函数属于该类型。接收者分两种，区别在于能不能修改原对象：

```go
// 值接收者：拿到的是副本，修改不影响原来的变量
func (u User) IsAdult() bool {
	return u.Age >= 18
}

// 指针接收者：拿到原对象的地址，可以修改它，也避免复制大对象
func (u *User) GrowUp() {
	u.Age++
}

// 使用示例（接上文 main 函数）：
// u := User{Name: "小明", Age: 12}
// u.GrowUp()
// fmt.Println(u.Age)        // 13
// fmt.Println(u.IsAdult())  // false
```

一条实用经验：只要方法需要修改接收者的字段，或者结构体比较大，就用指针接收者；只读的小结构体用值接收者没问题。Go 的自动取地址很贴心，`u.GrowUp()` 不用写成 `(&u).GrowUp()`。

定义结构体还有几个常用技巧：

- 字段首字母大写表示公开（其他包可以访问），小写表示私有，这是 Go 的访问控制方式；
- 结构体字面量可以只初始化部分字段，其余字段自动为零值（0、""、false）；
- 用 `==` 比较两个结构体，要求每个字段都可比较；
- 结构体可以嵌套别的结构体，或者用匿名字段实现"组合"，效果类似继承。

打个比方：结构体是表格的列定义，一个结构体变量就是表里的一行。以后你学到数据库时，会发现两者惊人地相似。

只声明不赋值也能创建结构体：var u User 会得到各字段都是零值的实例，数字为 0、字符串为空，很多场景这样已经够用。字段名全部省略的写法还能定义匿名结构体，适合只在一个函数里用一次的临时数据结构，不必为它起全局名字。另外 Go 没有类和继承，复用字段靠"结构体组合"：把一个结构体匿名嵌进另一个，外层就能直接访问内层的字段和方法，效果类似继承但更简单直接。

小结：结构体让我们能自定义类型、组织复杂数据，方法让类型拥有行为，值接收者和指针接收者的区别是本章重点。建议定义一个 Book 结构体（书名、价格、页数），给它写一个打折方法和一个是否贵过阈值的判断方法。

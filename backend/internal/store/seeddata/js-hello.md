## 第1章 · 在浏览器里运行第一行 JS

JavaScript（简称 JS）是唯一一种能在浏览器里直接运行的编程语言——你每天打开的网页里，点按钮弹窗、页面自动刷新、下拉菜单展开，背后都是它。所以学 JS 有个天然优势：不需要安装任何东西，有浏览器就能开工。

第一步是找到浏览器的"控制台"，那是专门给开发者运行代码、查看输出的地方。以 Chrome 或 Edge 为例：

- 按 F12（macOS 是 Option + Command + I）打开开发者工具；
- 点顶部或侧边的"Console"（控制台）标签；
- 在光标处输入代码，按回车立即执行。

在控制台里输入下面这行，回车：

```javascript
console.log("你好，JavaScript！");

console.log(1 + 2);   // console.log 也能输出计算结果：3

// 双斜杠是注释，写给人看的说明文字，浏览器会忽略
```

console.log 是 JS 里使用频率最高的语句，作用是往控制台打印内容，写代码时的"眼睛"——想确认某个变量是什么值，就打印它。另外两个弹窗函数也了解一下，它们直接操作页面：

```javascript
// alert 弹出提示框，页面会暂停等用户点确定
alert("页面加载完成！");

// prompt 弹出输入框，返回用户输入的字符串
let name = prompt("你叫什么名字？");
console.log("欢迎，" + name);
```

控制台适合学习和实验，但真正的代码要写进网页文件。新建一个 HTML 文件，用 script 标签把 JS 包起来，浏览器打开页面时就会执行：

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>我的第一个 JS 页面</h1>

    <script>
      // script 标签之间就是 JavaScript 代码
      console.log("页面正在运行 JS！");
      document.title = "标题被 JS 改掉了";
    </script>
  </body>
</html>
```

保存为 hello.html，双击用浏览器打开，再按 F12 看控制台，就能看到代码的输出；页面标签上的标题也变了——最后一行直接改动了网页本身，这是 JS 最与众不同的能力，第 5 章 DOM 操作会专门讲。

初学者需要注意的三件小事：

- 控制台报错时读第一行，它会告诉你是哪一行、出了什么问题，比如缺少括号、变量未定义；
- JS 严格区分大小写，console.log 写成 Console.log 会直接报错；
- 每行结尾的分号在现代 JS 里可写可不写，团队风格统一即可，本教程统一写上。

两个交互细节值得注意：prompt 的取消按钮返回 null，不是空字符串，后续处理输入前先判断一下；控制台的输出还分级别，console.warn 是黄色警告、console.error 是红色错误，写练习时可以有意识地用它们区分信息类型。控制台里还能直接查看变量的当前值：输入变量名回车即可，这是最朴素也最常用的调试手段，比想象中好用得多。现在就打开控制台，把本章三段代码各跑一遍。跑完试试输入 2 + 3 * 4 直接回车，控制台还能当计算器用。

小结：你已经搭好了 JS 的学习环境——浏览器控制台随写随跑，script 标签让代码进网页，console.log 是最可靠的调试伙伴。

## 第1章 · 数据库与表的概念

学 SQL 之前先弄清楚数据库是什么。数据库（Database）是专门用来存放和管理数据的软件，数据量大、并发访问多、要求不丢失的应用，都靠它存数据。你在购物网站下的订单、发过的评论，都躺在某台服务器的数据库里。我们日常说的"学 SQL"，就是学习用一种统一的语言和数据库对话——增删改查、统计分析都靠它。

数据库里组织数据的基本单位是表（table）。表就像 Excel 的工作表：竖的叫列（column），每一列有名字和类型；横的叫行（row），一行就是一条完整记录。比如一张学生表，四列分别是编号、姓名、班级、分数，每个学生占一行。

每一列都要声明数据类型，常见类型先记这几个：

- INTEGER：整数，如分数、数量；
- TEXT：文本字符串，如姓名、标题；
- REAL / FLOAT：小数，如价格、身高；
- DATE / DATETIME：日期和时间（不同数据库写法略有差异）；
- BOOLEAN：真或假。

除了类型，列上还可以加约束，最关键的是主键（primary key）：它的值在整张表里唯一，用来精确定位某一行，通常是自增的编号。此外 NOT NULL 表示该列不许为空。下面动手建一张表，SQL 关键词不区分大小写，但习惯上关键词大写、表名列名小写，一行的注释用两个短横线开头：

```sql
-- 创建一张学生表
CREATE TABLE students (
    id    INTEGER PRIMARY KEY,  -- 主键：每行的唯一编号
    name  TEXT NOT NULL,        -- 姓名，不允许为空
    class TEXT,                 -- 班级
    score INTEGER               -- 分数
);
```

表建好之后，用 INSERT 往里放数据。INSERT INTO 后面跟表名和列名列表，VALUES 里按列的顺序给值；文本值用单引号包起来。一次可以插入多行，写起来很紧凑：

```sql
-- 插入三行数据；自增主键 id 可以不写，数据库自动编号
INSERT INTO students (name, class, score) VALUES
    ('小明', '一班', 90),
    ('小红', '二班', 85),
    ('小刚', '一班', 77);
```

动手练习需要一个能跑 SQL 的环境，推荐从轻量的 SQLite 开始：

- 在线工具：搜索 "SQLite online"，浏览器里就能建表查询，零安装；
- 本地练习：SQLite 官网下载命令行工具，或用 VS Code 的 SQLite 插件；
- 手机练习：安卓上可安装 Termux 配合 sqlite3 命令，也能完整练习。

把建表和插入的语句在你的环境里跑一遍，就完成了数据库学习的第一步。顺便建立两个直觉：一是"表结构先行"——先想清楚有哪些列、什么类型，再存数据，这和写代码先想数据结构是同一个道理；二是 SQL 是声明式语言——你只描述"要什么数据"，不必写"怎么一步步找"，数据库自己会挑最高效的路径，这也是它和前面学的 Go、Python 最大的差别。

市面上的数据库产品很多：SQLite 轻量到整个数据库就是一个文件，适合学习和小工具；MySQL、PostgreSQL 是网站后端的主力；SQL Server、Oracle 常见于企业系统。它们都遵循 SQL 标准，核心语法高度一致，个别特性有方言差异，学会其中一种，换另一种只需查查差异点，不用从头再学。这也是 SQL 作为技能的投资价值所在：语法几十年几乎没变过，换项目、换公司都带得走。

小结：数据库存数据，表是基本单位，列有类型和约束，主键唯一标识一行；CREATE TABLE 建表，INSERT INTO 插数据；SQLite 是零成本上手的练习环境。

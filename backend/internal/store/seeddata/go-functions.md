## 第5章 · 函数与多返回值

函数是一段有名字、可以反复调用的代码。把常用逻辑写进函数，程序就能像搭积木一样组合起来：主流程读起来是几个函数调用，细节都藏在各自的函数里。Go 用 func 关键字声明函数，参数和返回值都必须写明类型，编译器会帮你检查每一次调用是否正确：

```go
package main

import "fmt"

// add 接收两个 int 参数，返回一个 int
// 两个参数类型相同时，可以合并写成 a, b int
func add(a, b int) int {
	return a + b
}

// greet 只打印不返回值，这类函数没有返回值类型
func greet(name string) {
	fmt.Println("你好，", name)
}

func main() {
	fmt.Println(add(3, 5)) // 8
	greet("小明")           // 你好， 小明
}
```

Go 最有特色的语言设计之一，是函数可以一次返回多个值。调用方用多个变量接住返回结果，这个特性在 Go 的代码里无处不在——最典型的就是第 9 章要讲的"返回值 + 错误"模式：

```go
import "errors"

// divide 一次返回商和余数两个值
func divide(a, b int) (int, int) {
	return a / b, a % b
}

// splitSum 使用可变参数：调用时可以传任意个 int，nums 在函数内是切片
// 返回值带了名字（total、err），函数体内可以直接把它们当变量用
func splitSum(nums ...int) (total int, err error) {
	if len(nums) == 0 {
		return 0, errors.New("至少要传一个数")
	}
	for _, n := range nums {
		total += n
	}
	return total, nil // 一切正常时错误返回 nil
}

// 调用示例：
// q, r := divide(17, 5)        -> q 是 3，r 是 2
// sum, err := splitSum(1, 2)   -> sum 是 3，err 是 nil
// q, _ := divide(17, 5)        -> 不需要的返回值用下划线 _ 忽略
```

关于函数的参数传递，有几点值得记住：

- Go 的参数按值传递：函数拿到的是副本，在函数内修改参数不影响外面的变量；
- 想让函数修改外部变量，可以传指针（下一章讲结构体时会大量用到）；
- 可变参数 `nums ...int` 在函数体内就是一个切片，可以用 range 遍历；
- 命名返回值适合返回值较多时提高可读性，但不要滥用；
- 函数在 Go 里是"一等公民"，可以存进变量、当作参数传给别的函数，这在学习接口和并发时会反复出现。

函数是组织代码的基本单位。写得好的函数有个共同特点：名字说清楚"做什么"，函数体只做一件事。当你发现一个函数超过几十行、或者名字里出现"和"字时，通常就该拆分了。

函数还能匿名定义并随时赋给变量，匿名函数可以"记住"定义处作用域里的变量，即使外层函数已经返回，这个特性叫闭包。闭包最经典的用法是计数器：外层函数定义一个局部变量并返回一个修改它的匿名函数，之后每次调用返回的函数，计数都会加一，那个变量在两次调用之间一直活着。闭包是 Go 里实现回调、中间件的基础构件，动手把计数器写出来，观察变量的生命周期，后面学并发时它还会大量出场。练习写完后，试着向自己解释：为什么那个局部变量没有被回收？

小结：这一章认识了函数的声明、参数、返回值，以及 Go 标志性的多返回值和可变参数。试着把第 4 章的"1 加到 100"改造成一个函数 sumTo(n int) int，让它能算 1 加到任意 n。

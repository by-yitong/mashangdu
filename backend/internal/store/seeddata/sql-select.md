## 第2章 · SELECT 基础查询

数据库世界里九成的语句是查询，查询的核心就是 SELECT。它的读法接近英语句子：SELECT 声明"要哪些列"，FROM 声明"从哪张表"，两者组合就是最基本的查询。本章继续使用第 1 章建好的 students 表（包含 id、name、class、score 四列，已插入三行数据）：

```sql
-- 查询所有学生的姓名和分数两列
SELECT name, score FROM students;

-- 星号 * 表示所有列，调试时方便，正式代码建议写明列名
SELECT * FROM students;
```

写明列名有两个好处：一是别人读 SQL 时不用查表结构就知道会得到什么；二是只取需要的列能减少数据传输，表越宽（列越多）、行越多，差别越明显。所以养成习惯：除了随手调试，SELECT 后面都写具体的列。

SELECT 的位置上除了列名，还可以放别名、计算和去重，让查询结果更贴近最终需要：

```sql
-- 用 AS 给列起别名，让结果更易读（AS 可以省略，但写上更清楚）
SELECT name AS 姓名, score AS 分数 FROM students;

-- SELECT 后面可以写表达式：每人加 5 分后的成绩
SELECT name, score + 5 AS 加分后 FROM students;

-- DISTINCT：去掉重复值，看看表里都有哪些班级
SELECT DISTINCT class FROM students;
```

三条语句各有用途：别名常用在报表里把英文字段名展示成中文；表达式说明 SELECT 后面是"每一行都算一遍"的公式；DISTINCT 只在统计"有哪些种类"时使用，注意它是对整行结果去重，如果查两列，去重就按两列的组合来。

查询语句还有几条通用规则值得记住：

- 关键词不区分大小写，SELECT 与 select 等价；但列名、表名在部分数据库里区分，建议统一小写；
- 一条语句以分号结尾；在命令行工具里，忘了分号时工具会一直等下一行；
- 注释用 `--`（单行）或 `/* ... */`（多行）；
- SQL 关键词的书写顺序基本固定：SELECT、FROM、WHERE、GROUP BY、ORDER BY、LIMIT，后面几章会把这条链补全；
- 空值不等于 0 也不等于空字符串，它参与比较时结果仍是空值，这是 SQL 出名的坑，第 3 章会给出正确判断方式。

如果你想现在就看到"只查一部分行"的效果，可以先偷跑一条：`SELECT * FROM students LIMIT 2;`——LIMIT 限制返回行数，表很大时先 LIMIT 看几行再写完整查询，是很有用的开发习惯。

配合第 1 章的内容，你已经掌握了数据库最常用的一组操作：CREATE TABLE 建表、INSERT INTO 放数据、SELECT 取数据。这三步对应着真实项目里的建库、写入、展示，虽然都还很朴素，但骨架已经齐全。

顺便一个冷知识：SELECT 后面不跟 FROM 也能执行，比如 SELECT 1 + 1; 直接返回 2，很多数据库用它做连通性测试或算个常量。这恰好揭示了 SELECT 的本质——"表达式求值再投影"：普通列名、别名、计算式在它眼里都是表达式，列名只是恰好要从表里逐行取值而已。理解了这一点，以后看到在 SELECT 里写函数、写 CASE 判断的查询就不会觉得奇怪了。

小结：SELECT 加 FROM 是查询的最小单位，写列名优于星号，AS 起别名，表达式按行计算，DISTINCT 去重。练习建议：分别查出"所有学生的班级去重列表"和"每个学生加 10 分后的姓名与成绩"。

## 第6章 · 切片与映射

写程序免不了要管理"一堆数据"：一列名字、一批订单、一张成绩表。Go 提供了多种集合类型，最常用的是切片（slice）和映射（map）。先说切片：Go 的数组长度固定、用得少，日常干活靠的是能在尾部自由增删的切片。用 make 创建一个空切片，再用 append 往里加元素，它会按需自动扩容：

```go
package main

import "fmt"

func main() {
	// make 创建一个长度 0、能自动扩容的字符串切片
	fruits := make([]string, 0)

	fruits = append(fruits, "苹果")
	fruits = append(fruits, "香蕉", "橘子") // append 可以一次加多个
	fmt.Println(fruits, "长度", len(fruits)) // [苹果 香蕉 橘子] 长度 3

	fmt.Println(fruits[0]) // 下标从 0 开始

	// 切出一部分：含头不含尾，得到一个新的切片视图
	part := fruits[1:3]
	fmt.Println(part) // [香蕉 橘子]
}
```

注意 append 的返回值必须接回来：`fruits = append(fruits, x)`。这是因为扩容时切片可能整体搬家，append 返回的是新位置，不接回来会丢失数据。这是 Go 新手最常见的坑之一。

映射则解决"按名字找东西"的问题：每个值都挂在一个唯一的键下面，查起来不用遍历，就像查字典一样。键的类型写在前、值的类型写在后，用 `map[string]int` 这样的形式声明：

```go
ages := map[string]int{
	"小明": 12,
	"小红": 13,
}

ages["小刚"] = 11    // 键不存在时是新增，已存在时是覆盖
delete(ages, "小红") // 用 delete 删除键值对

// 读取时接两个值：第二个 ok 表示键是否存在，不存在时零值是 0
score, ok := ages["小明"]
fmt.Println(score, ok) // 12 true

score2, ok2 := ages["小红"]
fmt.Println(score2, ok2) // 0 false
```

`v, ok := m[key]` 这个写法叫 comma-ok 惯用法。直接 `m[key]` 取不存在的键不会报错，只会拿到值类型的零值，有时这正是想要的，有时却会掩盖"键根本不存在"的事实，需要区分时一定要用两个返回值的形式。

日常使用这两种集合的要点：

- 切片用 len 看长度，用 append 增、用切片表达式裁剪、用 copy 复制；
- 遍历两者都用 `for i, v := range` 或 `for k, v := range`；
- 映射遍历顺序是随机的，别指望每次顺序一致；需要顺序就先把键取出来排序；
- 切片和映射都是引用类型：传给函数后，函数内对内容的修改会影响原数据；
- 映射的零值是 nil，直接往 nil 映射写数据会 panic，用前先 make。

切片还有一个容量概念：用 cap 函数查看，表示底层数组当前能容纳的元素个数。append 时若长度超过容量，Go 会分配一块更大的新数组并把数据搬过去，通常按现有容量的倍数增长。如果预先知道大概要存多少元素，可以直接 make([]int, 0, 100) 一次给足容量，避免反复搬家，性能敏感的场景里这是简单有效的优化。长度和容量是两个独立的数字，理解了它们，切片的行为就都好解释了。动手试试：连续 append 之后打印 len 和 cap，亲眼看一次扩容。光看不练学不会集合，把示例逐行敲一遍。

小结：切片管"一串数据"，映射管"按键查数据"，两者组合起来（比如 `map[string][]string`）就能表达很复杂的数据结构。建议写个小练习：把一批名字存进切片，统计每个名字出现的次数放进映射。

## 第4章 · 列表与字典

单个变量只能装一个值，真实的数据往往是"一批"：一个班的成绩、一本书的信息。Python 用列表（list）装一串有序的数据，用字典（dict）按名字存取数据，这两个容器是这门语言使用频率最高的结构，没有之一。

列表就像一排编了号的抽屉：元素按顺序排放，可以随时增删改。常见操作都围绕下标（从 0 开始）和内置方法展开：

```python
# 列表：有序、可修改的集合
scores = [90, 85, 77]

scores.append(88)     # 末尾添加
scores.insert(0, 60)  # 在指定位置插入
scores.remove(77)     # 按值删除第一个匹配项
print(scores)                  # [60, 90, 85, 88]
print(scores[0], scores[-1])   # 60 88（负下标从末尾数）
print(len(scores))             # 4

# for 直接遍历元素，这是最常用的姿势
for s in scores:
    print(s)

# 排序：sort 原地排序，sorted 返回新列表不动原数据
scores.sort()
print(scores)    # [60, 85, 88, 90]
```

列表只回答"第几个是什么"，字典回答"某个名字对应什么"。字典由键值对组成：键唯一（通常用字符串），值可以是任何类型。查字典的方式就是用方括号加键名，速度极快，哪怕有百万条数据也是一瞬间：

```python
# 字典：键值对，键唯一
student = {"name": "小明", "age": 12}

student["grade"] = "六年级"   # 键不存在时是新增，已存在时是覆盖
print(student["name"])        # 小明

# 访问不存在的键直接方括号会报 KeyError；get 更温和，返回 None 或默认值
print(student.get("phone"))          # None
print(student.get("phone", "未填写")) # 未填写

# 遍历键值对：items 一次给两个变量
for key, value in student.items():
    print(key, "=>", value)

print(list(student.keys()))    # ['name', 'age', 'grade']
```

两个容器还可以自由组合，表达复杂的数据结构，比如一个班的学生：

```python
# 列表里套字典：每个字典是一个学生
students = [
    {"name": "小明", "score": 90},
    {"name": "小红", "score": 85},
]

for st in students:
    print(f"{st['name']} 考了 {st['score']} 分")
```

使用时记住这几条经验：

- 列表保序，字典（Python 3.7 起）也按插入顺序遍历，但不要依赖字典的顺序做逻辑；
- 判断元素是否存在：列表用 `in`（慢），字典用 `in` 查键（快）；
- 修改列表时小心一边遍历一边删除，容易漏元素，可以先收集再统一删；
- 字典的键必须是不可变类型，字符串、数字、元组都行，列表不行；
- 列表和字典的赋值传的是引用：`b = a` 之后改 b 也会影响 a，想独立副本用 `a.copy()`。

排序还有两个进阶参数值得知道：reverse=True 表示降序；key 参数指定按什么排，比如字符串列表按长度排写 key=len，学生列表按分数排写 key=lambda s: s["score"]。另外预告一个 Python 特色写法：列表推导式，形如 [x * x for x in nums if x > 0]，一行完成映射加筛选，简洁有力，后续章节的示例代码里会经常见到它的身影。把两个容器的常用操作各敲一遍，列表和字典的手感就是这么练出来的。犹豫"该用列表还是字典"时，问自己一句：我是按位置取数据，还是按名字取数据？答案自然就出来了。

小结：列表管"一串东西"，字典管"按名字找东西"，两者嵌套能描述几乎任何数据——后面学 JSON 文件处理时你会看到一模一样的结构。练习建议：建一个通讯录字典（姓名到电话），实现添加、查询、删除三个操作，跑通一遍。

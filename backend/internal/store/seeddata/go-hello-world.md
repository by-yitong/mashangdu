## 从 Hello World 开始

每一门编程语言的第一课几乎都是 Hello World，Go 也不例外。它的作用很简单：让程序在屏幕上打印出一行文字，证明你的开发环境已经可以正常工作。请先在你的电脑上创建一个名为 hello 的文件夹，然后在里面新建一个文件 main.go，输入下面的代码：

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```

保存文件，在终端里进入这个文件夹，执行命令 go run main.go。如果一切顺利，你会看到屏幕上出现 Hello, World! 这行字。恭喜，你已经写出了第一个 Go 程序。

我们快速拆解一下这段代码的结构：

- `package main` 声明这是一个可以独立运行的主程序；
- `import "fmt"` 引入标准库里的格式化输出包；
- `func main()` 是程序入口，Go 程序总是从这里开始执行；
- `fmt.Println` 把括号里的内容打印到屏幕，并自动换行。

初次接触可能会觉得符号很多，这完全正常，先照着敲一遍、跑起来再说。编程是动手的学问，看得懂不等于写得出来。接下来你可以把引号里的文字换成自己的名字，再运行一次，亲眼看到输出变化，这一步比多看十页书更有成就感。

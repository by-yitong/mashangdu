## 变量与控制流：让程序会思考

上一章你在 REPL 里做过计算，这一章把两个最重要的基础概念连起来：变量负责存数据，控制流决定程序走哪条路。Python 的变量不需要声明类型，直接赋值就能用：

```python
name = "小红"
age = 12

if age < 18:
    print(name + " 是未成年人")
else:
    print(name + " 是成年人")
```

注意 if 那一行末尾的冒号，以及下一行开头的缩进。Python 用缩进表示代码块，同一块代码必须对齐，推荐 4 个空格。这是 Python 最独特的规则，缩进写错会直接报 IndentationError。

控制流常用的有三种结构：

- `if / elif / else`：按条件走不同分支，比如判断成绩等级；
- `for` 循环：逐个处理序列里的元素，比如列表中的每一项；
- `while` 循环：只要条件成立就反复执行，比如倒计时。

再看一个 for 循环的例子：

```python
for i in range(1, 4):
    print("第", i, "遍练习")
```

range(1, 4) 会依次产生 1、2、3，注意不包含 4，这是新手最容易踩的坑。变量给了程序记忆，控制流给了程序判断，掌握这两样，你就能写出自己的第一个小工具了。
